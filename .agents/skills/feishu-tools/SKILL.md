---
name: feishu-tools
description: 在飞书机器人任务中发送用户请求的附件或图片、报告长任务进展、查询本群历史与知识库、压缩当前上下文、重启机器人或通过家中音箱朗读。仅在 FEISHU_TOOL_CLI 可用的飞书任务中使用。
---

通过 `"$FEISHU_TOOL_CLI" <工具名> <参数>` 调用，参数按 shell 字符串正确引用；响应为 JSON，`ok=false` 必须如实报告。所有工作在本轮同步完成，最终结果写入最终回复。

| 工具 | 参数与用途 |
|---|---|
| `send_file` | 一个绝对文件路径；用户要求取文件时发送。普通文件，每个≤20MB，本轮工具附件最多3个 |
| `send_image` | 一个绝对图片路径；用户要求发图/图表时，以图片消息发送 |
| `send_text` | 一段文本；长任务有实质进展时可发送当前进展，最终答案仍写入最终回复 |
| `wiki_search` | 一个问题；本群问题需要知识库资料时按需检索 |
| `history_search` | 一个关键词；检索本群所有会话的数据库历史，最多20条 |
| `list_uploads` | 可选 `--limit 10`；`uploads` 是本群上传台账，`pending` 是仍待附带且未过期的缓冲，读取不消费 |
| `git_local_changes` | 无参数；只读查看当前任务工作目录的 git 改动 |
| `compact_context` | 无参数；登记压缩，在本轮完成后生成摘要，下一轮使用新上下文 |
| `restart_service` | 无参数；仅在用户要求重启时登记，本轮最终回复送达后才重启；需要用户先开 `/unsafe` |
| `speak` | 一段文本；用户明确要求音箱朗读/播报时使用，最多播放前200字，截断会返回说明 |

不得自行开启 `/permit` 或 `/unsafe`。工具上下文只能处理当前群、当前消息；不要改写 FEISHU_* 环境变量。

附件路径先确认已存在，发送失败不能声称已发送。工具已经发送的附件不要再写标记重复发送。只需在最终回复附文件时也可单独一行写 `[[SEND_FILE:/绝对路径]]`，同样每个≤20MB、最多3个；不要把该标记放进 `send_text`。

知识库返回 `reference`：优先按实际命中条目回答，保留原命令与参数，并附实际引用的文档标题与链接。未命中/不足时明确说明，再补充自己的知识。

重启是回复送达后的操作：只登记一次，不另拼 `systemctl restart`。任务失败或最终回复未送达会取消重启。成功调度后的启动状态由 bot 的「✅ 已启动」通知给出。

`speak` 同步进行 TTS 和 SSH 播放，不经过 bot socket。锁只覆盖 feishu-bot 各群，不能保证与其他音频程序互斥。缺 sink 返回 rc=99，不能声称播放成功。
