---
name: feishu-debate
description: 用户明确要求正反双方独立辩论时，在飞书任务内组织各五轮辩论并逐轮推送。双方分别使用独立 Codex 调用与各自历史，只交换最终发言。
---

从此文件所在目录运行 `scripts/debate.py`，用 `--topic` 传入用户辩题；使用当前 Python 或 `python3`。例如：

```bash
python3 "$FEISHU_DEBATE_SCRIPT" --topic '用户的辩题'
```

脚本同步完成双方各5轮发言，每轮通过 `send_text` 回到当前飞书消息。不要让单个上下文自己扮演双方；脚本为两方分别保留历史，只把对方最终发言转交，不共享推理内容。内部调用关闭外部工具，不落 bot 会话表，使用一次性 CLI 上下文。

脚本失败即停止，不自动重跑整场辩论，避免重复推送。最终回复简述双方核心分歧与结论；没有成功的轮次不声称已完成。
